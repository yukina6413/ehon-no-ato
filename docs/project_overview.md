# えほんのあと — プロジェクト概要

最終更新：2026-06-03

---

## アプリの目的

**「絵本を記録するアプリ」ではない。**

絵本を通して、保育士と子どもと保護者がつながり、子どもの育ちが未来に残っていくことを目的とする。

具体的には以下の4つを実現する。

| 目的 | 内容 |
|------|------|
| 絵本を通して子どもの姿を見る | 読み聞かせの場面で何が起きたかを記録・振り返る |
| 保育士がすぐに絵本を探せる | 今日必要な絵本を、3つの入口から素早く見つけられる |
| 日本の四季や自然との出会いを増やす | 季節を感じるテーマ設計で、子どもの感性を育てる |
| 子どもの育ちを未来に残す | 記録が積み重なり、成長の軌跡になる |

---

## 世界観

**日本の四季と自然を大切にする。**

春のうきうき、夏の暑さ、秋の落ち着き、冬の寒さ。
それぞれの季節を子どもが感じられる絵本との出会いを作ることが、このアプリの根幹にある。

行事だけでなく、雨の日の水たまり、土のにおい、虫の声、落ち葉のかさかさ感——
そういった**暮らしの中の感触**と絵本をつなぐことを意識して設計する。

保育士の余裕を作り、その余裕が子どもへの優しさになる循環を目指す。

---

## ターゲットユーザー

- 保育士（主担任・副担任）
- 幼稚園教諭・保育教諭
- 支援員

特に**仕事中に一瞬だけスマホを開く**ような使い方を想定する。
情報量を絞り、すぐに目的を達成できることを最優先とする。

## 画面構成

### 全体マップ

```
BottomNav
  ├── ホーム          絵本と出会う場所
  ├── 本棚            読んだ記録・お気に入りを管理する場所
  ├── 記録（中央）     今日の読み聞かせを記録する
  ├── カレンダー       行事・記録日をカレンダーで確認する
  └── マイページ       予定・設定を管理する場所
```

### 各画面の役割分担

| 画面 | 一言で言うと | 主な内容 |
|------|-------------|----------|
| ホーム | **絵本と出会う場所** | 絵本を探す・今のテーマ・子どもの姿から相談 |
| 本棚 | **記録を見る場所** | 読んだ本・お気に入り・読みたいリスト |
| 記録 | **記録する場所** | 絵本・クラス・反応を入力 |
| カレンダー | **行事を管理する場所** | 月カレンダー・行事登録 |
| マイページ | **管理・確認の場所** | 予定・タスク・週カレンダー・通知・設定 |

## ホーム画面

**「絵本と出会う場所」**

保育士が絵本を探すための3つの入口を提供する。予定管理・記録確認はマイページへ移動し、ホームは絵本との接点に特化している。

### 3つの入口

**1. 絵本・紙芝居を探す**
探したいものが決まっている保育士向け。
「七夕」「3歳 梅雨」のような短いキーワードでも、「太鼓の導入に合う紙芝居」のような自然文でも検索できる。
検索結果は別画面に遷移せず、ホーム内に展開される。

**2. 今のおすすめテーマ**
何を探せばいいか分からない保育士への入口。
行事と季節を分けず、「今の時期らしいテーマ」として提示する。
日本の四季・自然・生き物・暮らしを感じられる内容を優先する。
テーマと年齢を掛け合わせてさらに絞り込める。

**3. 子どもの姿から探す**
「旧AI絵本相談」の役割。探したい本が決まっていない保育士が、子どもの様子を言葉で入力して絵本を探せる。
「虫に興味がある子が多い」「帰りの会で落ち着いてほしい」のような保育場面の記述で提案が得られる。

→ 詳細は `docs/home_screen.md` を参照

## マイページ

**「管理・確認の場所」**

絵本を探す機能はホームに集約し、マイページは保育士の日常的な管理業務を担う。

### 構成（表示順）

1. **プロフィール** — 名前・園名・担当クラス・設定ボタン
2. **今日の確認** — 今日の予定 / 今日のやること / 記録したいこと（各3件まで）
3. **週カレンダー** — デフォルト表示。「月カレンダーを見る」で月表示に切り替え
4. **記録のふりかえり** — 今月の記録数・AIレポート閲覧数・記録した日数・よく読んだテーマ
5. **通知設定** — 行事前通知・読みたい絵本前日通知・記録忘れ通知をON/OFFで管理
6. **アカウント設定** — プロフィール編集・通知詳細設定

### 設計方針

- カレンダーは**週表示がデフォルト**。月表示はボタンで切り替え
- 月カレンダーの日付タップでその日の記録・行事を確認できる（絵本推薦は表示しない）
- 「今日の確認」は1枚のカードに3種類を集約し、スクロール量を抑制する

## 絵本詳細画面

**「保育士が実践に活かせる情報の場所」**

単なる絵本紹介ではなく、読み聞かせの実践から保護者連携まで使える情報を提供する。

### 掲載内容（表示順）

| # | 項目 | 説明 |
|---|------|------|
| 1 | 📖 あらすじ | 物語の内容（デフォルト展開） |
| 2 | 🎯 保育のねらい | 保育士が意図を持つための視点（デフォルト展開） |
| 3 | 🗣️ 読み方のヒント | 読む前・途中・終わった後の3フェーズで声かけ例を提示 |
| 4 | ✨ 子どもとの対話のきっかけ | 読み聞かせ中に生まれやすい反応・問いかけ |
| 5 | 👁️ この絵本で見えやすい子どもの姿 | 観察ポイントを箇条書きで列挙 |
| 6 | 💌 保護者へのおすすめ文 | おたより・配信・面談でそのまま使えるコピー可能な文章 |
| 7 | 🏠 家庭での楽しみ方 | 散歩・会話・季節の自然とつなげる提案 |
| 8 | 💡 活動例 | 保育活動への組み込み方 |

### UIの方針

- すべての項目を折りたたみカード形式で表示（スクロール量を抑制）
- 「あらすじ」「ねらい」のみデフォルトで展開
- 「保護者へのおすすめ文」にはクリップボードコピーボタンを設置
- フィールドが存在しない絵本では該当セクションを非表示にする（後方互換性）

→ 詳細は `docs/book_detail.md` を参照

## データ設計の方針

| データ種別 | 保存先 | 備考 |
|-----------|--------|------|
| やること | `localStorage`（日付別） | ホーム・マイページ共通で読み書き |
| 予定 | `localStorage`（`schedules_v1`） | ホーム・マイページ共通で読み書き |
| 読みたい本 | `localStorage`（`wantToRead_books`） | 絵本詳細から登録 |
| 絵本・記録データ | 現時点はモック | 将来：外部DB連携 |
| 検索結果 | コンポーネント内状態 | ページ離脱でリセット |
