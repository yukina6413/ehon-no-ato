# ホーム画面 仕様

最終更新：2026-06-03

## 画面の役割

**「絵本と出会う場所」**

ホーム画面は、保育士が絵本を探すための場所。
記録・管理・予定確認はマイページに集約し、ホームは絵本との接点に特化する。

保育士のよくある使い方を想定した3つの入口を提供する。

| 状況 | 入口 |
|------|------|
| 「七夕に合う絵本を探したい」| 絵本・紙芝居を探す |
| 「梅雨の時期の絵本は何がいいかな」 | 今のおすすめテーマ |
| 「虫に興味がある子が多い、どうしよう」 | 子どもの姿から探す |

---

## 画面構成（表示順）

```
ヘッダー（日付・アプリ名）
│
├── 今日のやること（ミニ表示）
│     最大3件 / 「予定を確認」でマイページへ
│
├── 絵本・紙芝居を探す
│     検索入力 + 例文チップ
│     → 結果はホーム内に展開（別画面移動なし）
│
├── 今のおすすめテーマ
│     月別テーマタグ（折り返し表示）
│     → テーマ選択で年齢フィルターが出現
│     → 結果はホーム内に展開
│
└── 子どもの姿から探す
      テキスト入力 + 例文チップ
      → 結果はホーム内に展開（別画面移動なし）
```

## セクション詳細

### 今日のやること（ミニ表示）

- その日の未完了タスクを最大3件だけ表示
- タップでチェックのトグルが可能
- 「予定を確認 →」からマイページへ遷移
- 詳細な追加・削除はマイページで行う
- **保存方式**：`localStorage`（日付単位）
- **翌日の扱い**：未完了タスクは翌日に自動引き継ぎ

---

### 絵本・紙芝居を探す

探したいものが決まっている保育士向けの直接検索。

**入力欄**

- プレースホルダー：`例：七夕、3歳 梅雨…`
- Enterキーまたは「検索」ボタンで実行

**例文チップ**（タップで入力補完 + 即検索）

```
七夕
3歳 梅雨
太鼓の導入に合う紙芝居
```

**結果表示**

- 同一カード内の下部に展開（別画面には遷移しない）
- 絵本カード形式で2〜3件表示
- タップで絵本詳細モーダルを開く

---

### 今のおすすめテーマ

何を探せばいいか分からない保育士に、今の時期らしい絵本との出会いを提供する。

#### テーマタグの設計方針

- 行事と季節を**分けない**（分類名を利用者に意識させない）
- 今の時期らしさを優先する
- **日本の四季・自然・生き物・暮らしを感じられる内容を優先する**
- 毎月固定で「誕生会」「避難訓練」を追加表示する

#### 月別テーマ例

| 時期 | テーマ例 |
|------|----------|
| 3月 | さくら・春風・ちょうちょ・たんぽぽ・芽吹き |
| 6月 | 雨・あじさい・かたつむり・水たまり・七夕 |
| 9月 | お月見・どんぐり・秋風・虫の声・実り |
| 12月 | 雪・冬の星・クリスマス・あたたかさ |
| 毎月 | 誕生会・避難訓練 |

季節テーマの詳細な選定基準は実装コードの `MONTHLY_THEMES` 定数を参照。

#### 年齢フィルター

テーマタグをタップすると、年齢選択ボタンが出現する。

```
0歳 ／ 1歳 ／ 2歳 ／ 3歳 ／ 4歳 ／ 5歳
```

- 年齢を選ばなくてもテーマ単体でおすすめが表示される
- 年齢選択後は「{テーマ} × {年齢}」でフィルタリングされた結果を表示
- 同一テーマをもう一度タップするとリセット

#### 表示形式

- **折り返し表示**（横スクロールなし）
- 画面内に収まるよう2行程度で折り返す
- 選択中のタグは緑背景でハイライト

### 子どもの姿から探す

旧「AI絵本相談」の役割。探したい本が決まっていない保育士が、子どもの様子や保育場面から絵本を相談できる入口。

**入力エリア**

- テキストエリア（2行、リサイズ不可）
- プレースホルダー：`例：虫に興味がある子が多い`

**例文チップ**（タップで入力補完 + 即検索）

```
帰りの会で落ち着いて聞いてほしい
虫に興味がある子が多い
七夕の導入をしたい
友だちとの関わりが増えている
```

**「絵本を探す」ボタン**

- 入力ありで有効化（琥珀色）
- 入力なしは非活性（グレー）

**結果表示**

- 同一カード内の下部に展開
- 「子どもの姿に合ったおすすめ」のラベルで絵本カードを表示

## 削除された要素（旧設計との差分）

| 旧セクション | 削除理由 |
|-------------|----------|
| 週カレンダー | マイページに移動 |
| 今日の予定（フル） | マイページに移動 |
| 今日のやること（フル管理） | マイページに移動 |
| 次回の行事 | マイページに移動 |
| 今日のおすすめ絵本（固定2冊） | 「今のおすすめテーマ」に統合 |
| 最近の記録 | 削除（本棚から確認） |
| 1年前の今日 | 削除（スクロール削減） |
| テーマから探す（折りたたみ） | 「今のおすすめテーマ」に統合 |
| 行事・季節から探す（横スクロール） | 「今のおすすめテーマ」に統合 |

## データ・状態管理

| データ | 保存先 | 備考 |
|--------|--------|------|
| 今日のやること | `localStorage`（`tasks_YYYY-MM-DD`） | Home・MyPage共通 |
| 検索結果 | コンポーネント内状態（`useState`） | 画面内一時表示 |
| テーマ選択状態 | コンポーネント内状態 | ページ離脱でリセット |
| 絵本詳細 | コンポーネント内状態（`selectedBook`） | モーダル表示 |
| 読みたい登録 | `localStorage`（`wantToRead_books`） | スケジュールにも追記 |
