# 検索機能 仕様

## 概要

絵本や記録をキーワードで検索する機能。本棚内検索とAI相談検索の2種類がある。

## 本棚内テキスト検索

- 対象：タイトル・著者名
- 場所：本棚画面のヘッダー内検索バー
- リアルタイム絞り込み（入力のたびに結果を更新）

## AI相談検索

- 自由文で絵本を相談・検索
- 場所：ホーム画面「AI相談検索」セクション
- 入力例：「午睡前に落ち着きたい」

## 将来的な検索軸

| 軸 | 例 |
|----|----|
| 年齢 | 3歳向け |
| テーマ | 食べ物、季節 |
| 場面 | 活動導入、午睡前 |
| 行事 | ひな祭り、七夕 |
| 反応タグ | 笑い、集中、もう一回 |

## 検索結果の表示

- 絵本カードのグリッド or リスト形式
- ヒット件数を表示
- 該当なしの場合は「まだ記録がありません」メッセージ
