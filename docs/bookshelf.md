# 本棚画面 仕様

## 概要

読み聞かせした絵本を管理する画面。タブで表示を切り替える。

## タブ構成

| タブ | 内容 |
|------|------|
| 読んだ本 | 記録済みの絵本一覧（最終読み日の新しい順） |
| お気に入り | お気に入り登録した絵本（最終読み日の新しい順） |
| 読みたい | ウィッシュリスト（追加した順） |
| ランキング | 子どもの反応が良かった絵本トップ5 |

## 並び順

- **読んだ本**：`lastRead`（最終読み日）の降順（新しい順）
- **お気に入り**：`lastRead`（最終読み日）の降順（新しい順）
  - お気に入り登録日ではなく、読んだ日が新しい順を採用
- **読みたい**：追加した順（古い順）
- **ランキング**：反応スコア順（固定）

## 「読みたい」への追加フロー

以下の経路から「読みたい」タブに絵本が追加される：

1. 本棚画面内での手動追加
2. ホーム画面「今日のおすすめ絵本」の「読みたいに追加」ボタン
3. ホーム画面「AI相談検索」の提案絵本への「読みたいに追加」ボタン

> AI提案・おすすめからの追加は「読んだ本」ではなく必ず「読みたい」に追加される。

## 絞り込み

- 年齢フィルター：すべて / 0歳〜5歳 / 混合
  - ランキング・読みたいタブでは非表示
- テキスト検索：タイトル・著者名

## 絵本カード（グリッド）

- 表紙（絵文字＋背景色）
- タイトル・著者
- 読んだ回数
- 最終読み日

## 絵本カードタップ時

- 絵本詳細画面（`/bookshelf/:id`）に遷移する
- 詳細画面の仕様は `docs/book_detail.md` を参照
