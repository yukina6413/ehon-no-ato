# 本棚画面 仕様

## 概要

読み聞かせした絵本を管理する画面。タブで表示を切り替える。

## タブ構成

| タブ | 内容 |
|------|------|
| 読んだ本 | 記録済みの絵本一覧（日付順・新しい順） |
| お気に入り | お気に入り登録した絵本 |
| 読みたい本 | ウィッシュリスト |
| ランキング | 子どもの反応が良かった絵本トップ5 |

## 並び順

- **読んだ本**：`lastRead`（最終読み日）の降順（新しい順）
- **お気に入り**：同上
- **読みたい**：追加した順
- **ランキング**：反応スコア順（固定）

## 絞り込み

- 年齢フィルター：すべて / 0歳〜5歳 / 混合
- テキスト検索：タイトル・著者名

## 絵本カード（グリッド）

- 表紙（絵文字＋背景色）
- タイトル・著者
- 読んだ回数
- 最終読み日
