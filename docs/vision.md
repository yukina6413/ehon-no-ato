# えほんのあと

===
\*

* 絵本のあとに残る、
* 子どもの気持ちを未来へ。
* 
* 保育士が絵本と子どもの反応を記録し、
* 日案・週案・月案・振り返りに活用できる
* 保育データアプリ。
* 
* ホーム画面は
* 「今知りたいこと」
* 「今日必要なこと」
* を優先表示する。
* 
* 過去の記録を見るアプリではなく、
* 今日の保育を助けるアプリとする。



## アプリの目的

保育士が絵本の読み聞かせ記録を手軽に残し、子どもたちの育ちや興味を振り返れるアプリ。

## ターゲットユーザー

* 保育士（主担任・副担任）
* 幼稚園教諭

## コアバリュー

* 記録のしやすさ（短時間で入力できる）
* 振り返りのしやすさ（過去の記録をすぐ引き出せる）
* 保育の質向上（AIおすすめ・相談機能で絵本選びをサポート）

## 将来的な展望

* 音声入力による記録
* 保護者との記録共有
* クラス・園単位での絵本データ活用
