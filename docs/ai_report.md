# AI相談・レポート機能 仕様

## 概要

保育士が自由文で絵本選びを相談できる機能。
クラスの興味・行事・場面などをもとに、AIがおすすめ絵本を提案する。

## ホーム画面での実装（現時点）

- ホーム画面の「AI相談検索」セクションとしてインライン展開する
- 別画面（`/ai`）への遷移はしない
- タップで入力欄を展開、もう一度タップまたは×で閉じる
- サジェスト例文を3件表示

### 入力例（サジェスト）

- 「午睡前に落ち着きたい」
- 「ひな祭りを5歳に説明したい」
- 「デカルコマニーの導入に合う絵本」

### 提案結果の表示（将来実装）

- おすすめ絵本を2〜3冊提案
- 各絵本に「なぜこの絵本か」の一言コメントを付ける
- 各絵本に「読みたいに追加」ボタンを設置
  - タップすると本棚の「読みたい」タブに追加される（「読んだ本」には追加しない）
- **現時点**：検索結果表示は将来実装。ボタンを押してもモック or 非表示で対応

## `/ai` 画面（将来用）

- パス：`/ai`、ファイル：`src/pages/AI.jsx`
- 現時点ではBottomNavに追加しない
- 将来的に独立した相談画面として拡張する想定
- ホーム画面のインライン実装で機能確認後、独立化を検討する

## 絵本詳細画面のAIレポート

- 絵本詳細画面（`/bookshelf/:id`）にも「この本のAIレポート」セクションを設ける
- 詳細は `docs/book_detail.md` を参照
