# 絵本詳細画面 仕様

## 概要

1冊の絵本についての詳細情報・読み記録をまとめて確認できる画面。
本棚またはホームの最近の記録カードからタップして遷移する。

## パス・ファイル

- パス：`/bookshelf/:id`
- ファイル：`src/pages/BookDetail.jsx`

## 遷移元

- 本棚画面（読んだ本・お気に入りのカードタップ）
- ホーム画面「最近の記録」のカードタップ

---

## 表示内容

### 1. 絵本の基本情報

| 項目 | 内容 |
|------|------|
| 絵本タイトル | テキスト表示 |
| 著者 | テキスト表示 |
| 出版社 | テキスト表示（未登録の場合は空欄） |
| 表紙イメージ | 絵文字＋背景色で代替（将来：画像対応） |

### 2. 読み記録サマリー

- 読んだ回数（合計）
- 最終読み日
- 読んだクラス（複数クラスがある場合はタグで表示）

### 3. 子どもの反応記録（記録一覧）

- 過去の読み聞かせ記録を時系列で一覧表示（新しい順）
- 各記録に以下を表示：
  - 読んだ日付
  - 読んだクラス
  - 子どもの反応テキスト
  - 反応タグ（例：😊笑い、🎯集中、🔁もう一回、🌙余韻、💬言葉返し）
- 「記録を追加」ボタンで記録入力画面（`/record`）に遷移

### 4. この本のAIレポート

- この絵本に関するAIからのコメント・分析を表示
- 表示例：
  - 「この絵本が子どもたちに与える影響」
  - 「読み聞かせのおすすめシーン・場面」
  - 「合わせて読みたい絵本」
- **現時点**：モックテキストで表示
- **将来**：記録データをもとにAIが自動生成

### 5. 読みたい本への追加 / 削除

- 「読みたいに追加」ボタン（未追加の場合）
- 「読みたいから削除」ボタン（追加済みの場合）
- タップすると本棚の「読みたい」タブに反映される

---

## アクション

| アクション | 内容 |
|-----------|------|
| 記録を追加 | 記録入力画面（`/record`）に遷移。この絵本が入力欄にあらかじめセットされた状態で開く |
| お気に入り登録/解除 | ハートアイコンまたはボタンでトグル。本棚の「お気に入り」タブに反映 |
| 読みたいに追加/削除 | ボタンでトグル。本棚の「読みたい」タブに反映 |

---

## データ未入力の場合の表示

| 項目 | 記録がない場合の表示 |
|------|---------------------|
| 出版社 | 空欄（「未登録」などは表示しない） |
| 子どもの反応記録 | 「まだ記録がありません」＋「記録を追加」ボタン |
| AIレポート | 「記録が増えると分析できるようになります」と表示 |
